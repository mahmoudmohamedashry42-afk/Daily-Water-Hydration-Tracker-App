# Daily Water & Hydration Tracker App 💧
تطبيق تتبع شرب الماء والترطيب اليومي

تطبيق تفاعلي مبني باستخدام **Flutter & Dart** لحساب وتتبع الاحتياج اليومي التقديري من الماء استناداً إلى الوزن (Weight)، وساعات النشاط البدني (Activity Hours)، والعمر (Age)، والجنس (Gender)، مع واجهة داكنة عصرية (Dark Theme) متوافقة بالكامل مع مواصفات التكليف العملي.

---

## مميزات التطبيق (Features)

1. **الشاشة الأولى: شاشة الإدخال (Input Screen)**
   - **سأر الصفحة (AppBar):** يحمل عنوان التطبيق مع أيقونة قطرة الماء وزر إعادة الضبط (Reset to Defaults).
   - **بطاقتي اختيار الجنس (Gender Cards):** اختيار متبادل بين (MALE / FEMALE) مع إبراز البطاقة المحددة بحدود ولون يوحي بالماء (`#00E5FF`).
   - **محدد ساعات النشاط (Activity Slider):** من 0 إلى 8 ساعات يومياً مع عرض فوري للقيمة.
   - **بطاقتي الوزن والعمر (Counter Cards):** 
     - الوزن من 30 إلى 200 كجم (الافتراضي: 60 كجم).
     - العمر من 10 إلى 100 سنة (الافتراضي: 20 سنة).
     - أزرار دائرية مخصصة للزيادة والنقصان (+) و (-).
   - **زر الحساب (Bottom Button):** زر عريض أسفل الشاشة للتحقق من المدخلات ثم الانتقال لشاشة النتيجة مع تمرير البيانات.

2. **الشاشة الثانية: شاشة النتيجة (Result Screen)**
   - **بطاقة النتيجة المركزية (Result Card):** عرض النتيجة بتنسيق بارز (مثال: `2.95 L / Day`) مع شريط بصري للترطيب وأيقونة الماء.
   - **توضيح التقدير (Disclaimer):** توضيح واضح وصريح بأن القيمة تقديرية لمعادلة تعليمية وليست نصيحة طبية شخصية.
   - **النص التوجيهي (Guidance Text):** رسائل توجيهية متغيرة حسب النتيجة (< 2.0 لتر، 2.0 إلى 3.0 لتر، > 3.0 لتر).
   - **ملخص المدخلات (Input Summary):** عرض مختصر للجنس، والوزن، والعمر، وساعات النشاط.
   - **زر إعادة الحساب (Re-calculate):** للرجوع إلى الشاشة الأولى باستخدام `Navigator.pop(context)`.

3. **التصميم ومنع أخطاء التجاوز (Design & Responsiveness)**
   - استخدام لوحة الألوان المحددة:
     - خلفية التطبيق: `#0A0E21`
     - البطاقة النشطة: `#1D1E33`
     - البطاقة غير النشطة: `#111328`
     - اللون الأساسي للماء: `#00E5FF`
     - النصوص: `#FFFFFF` و `#B0BEC5`
   - استخدام `SafeArea` و `SingleChildScrollView` لمنع أي `RenderFlex overflow` على مختلف أحجام الشاشات.

## 🧮 المعادلة الحسابية (Calculation Formula)

تم تنفيذ الحساب داخل دالة برمجية مستقلة في `lib/utils/water_calculator.dart`:

```dart
double calculateWaterLitres({
  required int weightKg,
  required double activityHours,
}) {
  final int baseMl = weightKg * 35;              // الاحتياج الأساسي
  final double activityMl = activityHours * 250;  // نشاط إضافي
  final double totalMl = baseMl + activityMl;     // الإجمالي بالميلليتر
  return totalMl / 1000;                          // التحويل إلى لتر
}
```

### أمثلة اختبارية (Test Cases):
- **50 كجم، 0 ساعة نشاط:** `1750 + 0 = 1750 ml` ⬅️ **1.75 L / Day**
- **60 كجم، 8 ساعات نشاط:** `2100 + 2000 = 4100 ml` ⬅️ **4.10 L / Day**
- **70 كجم، 2 ساعة نشاط:** `2450 + 500 = 2950 ml` ⬅️ **2.95 L / Day**
- **90 كجم، 4 ساعات نشاط:** `3150 + 1000 = 4150 ml` ⬅️ **4.15 L / Day**

    ├── constants.dart             # ثوابت الألوان ونصوص التصميم
    └── water_calculator.dart      # منطق الحسابات والنصوص التوجيهية

## 🛠️ الـ Widgets الأساسية المستخدمة (Core Widgets)

- `MaterialApp` & `ThemeData`: توحيد النمط الداكن والألوان.
- `Scaffold` & `AppBar`: الهيكل الرئيسي وشرائط العناوين.
- `SafeArea`: حماية العناصر من حواف ونوتش الشاشات.
- `SingleChildScrollView`: منع أخطاء الـ overflow في الشاشات الصغيرة.
- `Column` & `Row`: الترتيب الرأسي والأفقي للعناصر.
- `Expanded` & `Container`: توزيع المساحات وضبط الحواف وتدرج الألوان.
- `Slider` & `SliderTheme`: شريط تحديد ساعات النشاط وتخصيص مظهره.
- `GestureDetector`: التقاط النقرات على بطاقات الجنس.
- `ElevatedButton` & `RawMaterialButton`: أزرار التحكم الدائرية والأزرار السفلية.
- `Navigator` (`push` / `pop`): التنقل السلس بين الشاشات مع تمرير البيانات.

## 🚀 كيفية تشغيل المشروع (How to Run)

1. تأكد من تثبيت بيئة Flutter.
2. افتح المجلد في موجه الأوامر (Terminal):
   ```bash
   flutter pub get
   ```
3. تشغيل الاختبارات للتأكد من سلامة الكود:
   ```bash
   flutter test
   ```
4. تشغيل التطبيق على المحاكي أو جهاز حقيقي:
   ```bash
   flutter run
   ```
